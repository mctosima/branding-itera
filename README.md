# Itera Reputation Radar: demo

Prototipe pemantauan pemberitaan berbasis AI untuk FGD Branding Itera: Identitas, Narasi, Reputasi (5 November 2026),
sesi panelis AI & Teknologi.

Demo: https://mctosima.github.io/branding-itera/

- Data: judul berita publik dari Google News (12 bulan terakhir).
- Label topik, nada, dan kata kunci: dibuat otomatis oleh LLM. Bisa keliru, jadi perlu divalidasi manusia.
- Kasus sensitif hanya ditampilkan sebagai kategori dan jumlah, tanpa judul, nama, atau tautan.
- Prototipe untuk diskusi, bukan penilaian resmi institusi.
